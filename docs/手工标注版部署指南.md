# JotMark 手工标注版部署指南（Ubuntu）

这份指南给**第一次使用 Linux、不会编程的人**准备。完成后可以在没有 NVIDIA 显卡、CUDA、SAM、YOLO、模型权重的电脑上使用 JotMark 做手工标注。

本指南适用于 Ubuntu 22.04 或 24.04 桌面版。Windows 原生系统不能直接执行本项目的 `.sh` 启动脚本；如需 Windows，请使用 WSL2 + Ubuntu，或另行制作 Windows 安装包。

## 1. 这个版本能做什么、不能做什么

可以使用：

- 导入本地图片文件夹；
- 手动画矩形、多边形、折线、关键点、旋转框；
- 建立类别，填写公共属性、类别属性和每个标注的属性值；
- 保存 JSON，或导出 YOLO TXT、VOC XML；
- 自动保存、撤销/重做、修改类别和编辑标注。

本版刻意不包含：

- SAM2、SAM3、YOLO 的预测或分割辅助；
- 模型权重、PyTorch、CUDA、NVIDIA 驱动；
- 内嵌 YOLO 训练平台。

因此，**不要下载或复制 `sam3.pt`、其他模型 `.pt` / `.onnx` 文件到这台电脑**。它们不是手工标注所需内容。

## 2. 发给对方前，发送者要准备的内容

请把项目压缩成一个 ZIP，再发送给对方。压缩包里应保留源代码、`scripts/`、`ui/`、`jotmark/`、`docs/` 和下列新增文件：

- `scripts/install_manual_annotation.sh`
- `scripts/run_manual_annotation.sh`
- `Install-JotMark-Manual-Linux.sh`
- `Start-JotMark-Manual-Linux.sh`
- `Install-JotMark-Manual-Windows.bat`
- `Start-JotMark-Manual-Windows.bat`
- `scripts/install_manual_annotation_windows.bat`
- `scripts/run_manual_annotation_windows.bat`
- `scripts/create_condlanenet_list.py`
- `requirements-manual.txt`
- `docs/CurveLanes-CondLaneNet导出与训练.md`

压缩包中不要包含个人数据、令牌、模型、Python 环境和 Git 历史。请在项目的上一级目录打开终端，执行：

```bash
cd /home/nex
zip -r JotMark-手工标注版.zip JotMark-Desktop \
  -x 'JotMark-Desktop/.git/*' 'JotMark-Desktop/.venv*/*' \
     'JotMark-Desktop/.vendor/*' 'JotMark-Desktop/.runtime/*' \
     'JotMark-Desktop/.aws/*' 'JotMark-Desktop/.agents/*' 'JotMark-Desktop/.codex/*' \
     'JotMark-Desktop/weights/*' 'JotMark-Desktop/runs/*' \
     'JotMark-Desktop/datasets/*' 'JotMark-Desktop/TrainingPlatform/*' \
     'JotMark-Desktop/__pycache__/*' '*.pyc' '*.pt' '*.onnx' '*.pem' '*.key' \
     'JotMark-Desktop/.env' 'JotMark-Desktop/.env.*'
```

压缩前可检查 ZIP 中不含模型、环境或密钥：

```bash
unzip -l JotMark-手工标注版.zip | grep -Ei '\.(pt|onnx|pyc)$|/weights/|/\.venv|/\.git/'
```

如果这条检查没有输出，说明没有将上述不应分发的内容打入压缩包。`zip` 或 `unzip` 命令不存在时，在 Ubuntu 上执行：

```bash
sudo apt update
sudo apt install -y zip unzip
```

## 3. 对方电脑首次部署（只做一次）

### 第 1 步：联网并解压

首次安装需要联网下载约定的 Python 图形和图像处理组件。下载完成后，日常手工标注不需要网络。

1. 将 `JotMark-手工标注版.zip` 复制到对方电脑的“下载”目录。
2. 在文件管理器中右键 ZIP，选择“提取到此处”。
3. 解压后应得到一个 `JotMark-Desktop` 文件夹。若名称不同也没有关系，后续命令按实际文件夹名称填写。

建议把文件夹放在用户主目录下，例如：

```text
/home/用户名/JotMark-Desktop
```

不要放在 U 盘、系统目录或带有频繁同步的网盘目录中，以免保存标注时中断或权限不足。

### 第 2 步：打开终端

按键盘 **Ctrl + Alt + T** 打开“终端”。这是 Ubuntu 的命令窗口。

先进入项目目录。假设它解压在“下载”文件夹：

```bash
cd ~/下载/JotMark-Desktop
```

如果系统的下载目录显示为英文，请改用：

```bash
cd ~/Downloads/JotMark-Desktop
```

确认成功后，终端最末尾会显示类似 `JotMark-Desktop$`。可以用下面命令确认当前目录内有安装脚本：

```bash
ls scripts
```

应该能看到 `install_manual_annotation.sh` 和 `run_manual_annotation.sh`。

### 第 3 步：一键检测、安装并启动（推荐）

仍在项目目录下，执行：

```bash
chmod +x Install-JotMark-Manual-Linux.sh Start-JotMark-Manual-Linux.sh
./Start-JotMark-Manual-Linux.sh
```

启动脚本会先检查 Python 3.10+、`venv` 和项目虚拟环境：环境完整时直接启动；缺少 Python、`python3-venv` 或 `pip` 时，会在 Ubuntu / Debian 上自动调用 `apt` 安装 Python 与 Qt 图形运行库，并按提示请求登录密码；项目虚拟环境或依赖不完整时会自动修复。不会安装 CUDA、NVIDIA 驱动、PyTorch、SAM、YOLO 或模型。

安装过程中会自动创建项目内的 `.venv-jotmark-manual` 文件夹并下载依赖。下载前会短时测速清华 TUNA、中科大、阿里云和官方 PyPI 的 HTTPS 响应时间，并仅在本次安装中使用当前最快的可用源；不会修改系统全局 pip 设置。请保持网络连接，不要关闭终端。正常结束时会看到：

```text
手工标注环境检查通过
安装完成。
```

若执行 `./scripts/...` 时提示“权限不允许”，重新执行上一条 `chmod +x ...` 命令。

如只想安装或修复环境、暂不启动界面，也可执行：

```bash
./Install-JotMark-Manual-Linux.sh
```

## 4. 每次启动

1. 按 **Ctrl + Alt + T** 打开终端。
2. 进入项目目录，例如：

```bash
cd ~/下载/JotMark-Desktop
```

3. 执行：

```bash
./Start-JotMark-Manual-Linux.sh
```

程序会以最大化窗口打开。顶部只显示“手动标注”；看不到智能、模型、训练等按钮是正常的，说明当前确实处于无模型手工版。

### 可选：在桌面建立启动图标

确认能正常启动后，可在文件管理器打开项目目录，右键 `scripts/run_manual_annotation.sh`，选择“属性 → 权限”，勾选“允许作为程序执行”。之后可双击该文件启动；若桌面环境询问，选择“在终端中运行”。

不同 Ubuntu 桌面版本对双击 Shell 脚本的支持不同，所以**终端启动方式是最可靠的方法**。

## 5. 第一次手工标注的完整流程

### 5.1 准备图片

把待标注图片单独放到一个文件夹，例如：

```text
~/图片/待标注
```

建议只放图片（JPG、PNG、BMP、WebP、TIFF 等），不要混入其他人的 JSON、TXT 或 XML，避免混淆。

### 5.2 打开图片文件夹

在 JotMark 左上角点击 **打开目录**，选择“待标注”文件夹。右侧“文件列表”默认仅显示图片名称，避免长路径挤占空间；点击标题旁的 **后缀** 可显示或隐藏 `.jpg`、`.png` 等文件格式。点击文件名可切换图片。

### 5.3 建立类别

在右侧最大的“历史类别”区域中添加类别，例如 `person`、`car`、`defect`。类别操作按钮下方有独立的长输入框，适合输入和检查较长的英文类别名称；输入后按 Enter 或点击 **+** 即可添加。开始画某个标注前，先选中相应类别。

类别名称最好固定后再大量标注。YOLO 导出时，类别顺序会决定数字编号；中途随意删除、插入或改名可能影响已有训练数据的对应关系。

新建图片项目时，如果图片目录不存在 `classes.txt`，程序会自动加载 `examples/classes.example.txt` 中的默认类别：`person`、`car`、`cyclist`，并保存为该项目的 `classes.txt`。该模板是 UTF-8 文本，一行一个类别；以 `#` 开头的说明行会忽略。可复制并修改该文件，再点击右侧类别区域的 **导入** 按钮加载：未标注时可替换或追加，已有标注时只能追加，以避免类别编号与已有 YOLO 标签错位。

右键点击一个类别可进行重命名、属性管理或删除。选择 **删除类别及其全部标注** 后，必须点击 **我已确认，继续删除** 才会继续；程序会删除当前图片中该类别的全部标注、该类别专属属性，并同步清理当前标注输出目录内 JSON、XML、YOLO 文件中的此类别；YOLO 中后续类别编号会自动前移。请先备份重要数据。

右侧类别下的每个具体标注行可直接左键选中，画布与“标注属性”会同步到该标注。右键具体标注可修改类别或删除；删除单个标注会出现简洁确认框。也可以在 **选择/编辑（V）** 模式下，将具体标注拖到另一类别下更换类别。

### 5.4 选择标注工具并绘制

左侧工具栏可使用：

| 工具 | 用法 |
| --- | --- |
| 选择/编辑（V） | 选择、移动、调整已画出的标注。 |
| 矩形（R） | 在目标外侧按住左键并拖动。 |
| 多边形（P） | 单击依次添加顶点；双击或按 Enter 闭合。 |
| 折线（L） | 单击添加节点；双击、Enter 或右键结束。 |
| 关键点（T） | 按当前骨架模板放置关键点。 |
| 旋转框（O） | 拖动绘制，选中后可用 `Z/V` 每次旋转 5°，`X/C` 每次旋转 1°。 |

常用快捷键：`Ctrl + S` 保存、`Ctrl + Z` 撤销、`Ctrl + Shift + Z` 重做、`Delete` 删除所选标注、`Page Up/Page Down` 切换图片。

### 5.5 为标注填写属性（可选）

1. 在类别区点击 **公共**，添加所有类别共用的属性；例如“审核状态”。
2. 选中某一类别后点击 **属性**，添加只对该类别有效的属性；例如“颜色”“损坏类型”。
3. 可为属性添加子属性、可选值，并设置为单选、多选、文本、数值或是/否。是/否属性提供独立的 **是**、**否** 和 **清除** 按钮；“否”会作为真实值保存，不等同于未填写。
4. 在画布上或右侧具体标注行中选中一个框、多边形、折线、点等标注。右侧“标注属性”会出现“公共属性”和“类别属性”。点击它们，再点击属性当前值，即可从弹出的完整列表选择或更换值；单选值可反复更换。
5. 如已有属性模板，点击右侧类别区的 **属性导入** 并选择 `class_attributes.json`。若项目已有属性配置，程序会先在 `.jotmark_backups` 自动备份后再替换定义；打开图片目录时自动读取同目录 `class_attributes.json` 的原有机制仍保留。

属性定义保存为图片目录内的 `class_attributes.json`；每一个标注实际选中的值保存到相应 JSON 文件的 `attributes` 字段。

### 5.5.1 安全转换类别和属性

右侧类别区点击 **转换**，或右击类别选择 **安全转换类别 / 属性**，可把一个类别合并到另一个类别、把单值属性提升为类别，或把类别降为某个属性值。例如 `boundary_kind=curb` 可变为 `boundary_curb`，也可反向转回。

转换结果必须保存到与源项目不同且尚不存在的新文件夹。开始后程序会先在源目录 `.jotmark_backups` 建立完整快照，再生成新的完整项目；原项目不会改写。多选属性不能直接提升为类别。

### 5.6 选择保存格式并保存

左侧可选择 JSON、YOLO、XML 或 **CurveLanes / CondLaneNet 折线格式**。点击顶部保存图标或按 `Ctrl + S`。

- **JSON（建议作为主文件）**：保留所有形状、类别和属性；文件与图片同名，例如 `image_001.json`。
- **YOLO TXT**：保留类别和几何坐标，适用于 YOLO 数据集；不保存任意属性。
- **VOC XML**：保留类别和几何坐标；不保存任意属性。
- **CurveLanes / CondLaneNet**：仅导出开放折线为同名 `.lines.txt`，每行一条 `x1 y1 x2 y2 ...` 原图坐标；该格式没有类别或属性。完整训练目录和 `train.txt` / `valid.txt` 清单生成方式见 [CurveLanes-CondLaneNet 导出与训练说明](CurveLanes-CondLaneNet导出与训练.md)。

默认保存到图片同目录。需要把标注集中保存到别处时，点击顶部 **保存目录** 后选择一个空文件夹。不要在标注中途切换保存目录，否则同一批图片的标注可能分散在多个位置。

程序也会在编辑后自动保存 JSON；重要任务完成后仍建议按一次 `Ctrl + S` 并备份整个图片目录。

## 6. 建议的文件整理方式

最简单可靠的结构：

```text
项目A/
├── images/                 # 原始图片
│   ├── 0001.jpg
│   ├── 0001.json           # JSON 标注（推荐保留）
│   ├── 0002.jpg
│   └── 0002.json
└── backup-2026-10-28/      # 定期备份整个 images 文件夹
```

如果要交付 YOLO 训练数据，可另建导出目录保存 `.txt`，但请始终保留 JSON 原始标注和 `class_attributes.json`，因为 YOLO / XML 无法恢复属性。

## 7. 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 第一次启动提示需要密码或正在安装 Python / 图形组件 | 正常。启动脚本正在自动配置 Ubuntu / Debian 的 Python、venv、pip 和 Qt 图形库；输入登录密码并等待完成。 |
| `python3-venv` 不存在或创建环境失败 | 直接重新运行 `./scripts/run_manual_annotation.sh`；它会自动尝试安装。若电脑不是 Ubuntu / Debian，请让管理员按系统的软件管理器安装 Python 3.10+、venv、pip、OpenGL / EGL / XCB Cursor 图形库。 |
| `Permission denied` / 权限不允许 | 在项目根目录执行 `chmod +x Install-JotMark-Manual-Linux.sh Start-JotMark-Manual-Linux.sh`。 |
| 提示找不到手工标注环境 | 运行 `./Start-JotMark-Manual-Linux.sh`，它会自动检查并修复；不要直接运行通用的 `run_desktop.sh`。 |
| 打不开程序或一闪而过 | 必须从终端运行 `./Start-JotMark-Manual-Linux.sh`；把终端最后 20 行报错截图给维护者。 |
| 提示 `libGL.so.1`、`libEGL.so` 或 `xcb` 缺失 | 执行 `sudo apt install -y libgl1 libegl1 libxcb-cursor0`，然后重试。 |
| 没有“智能”“SAM”“训练”按钮 | 正常现象。这是无模型手工版，故意隐藏。 |
| 看不到以前的属性 | 打开图片目录时必须与原始 `class_attributes.json` 放在同一目录；并使用 JSON 格式保存的标注。 |
| 导出的 YOLO / XML 没有属性 | 正常。两种格式不支持本项目的任意属性；请保留 JSON。 |
| 图片无法打开 | 确认图片未损坏，格式为 JPG、PNG、BMP、WebP、TIFF 或 GIF；文件路径避免特殊权限目录。 |
| 要迁移到另一台电脑 | 复制整个图片目录（包含图片、JSON、`class_attributes.json`）即可；程序目录可重新按本指南安装。 |

## 8. 更新、卸载与数据安全

### 更新程序

先备份图片和标注目录，再用新版 ZIP 解压到一个新的 JotMark 文件夹，重复“首次部署”。不要直接覆盖旧目录中的 `.venv-jotmark-manual`。

### 卸载程序

先确认数据已备份，然后删除 JotMark 项目文件夹即可。若只想释放安装依赖占用的空间，删除其中的 `.venv-jotmark-manual` 文件夹；这不会删除放在其他图片目录中的标注。

### 必须备份的内容

至少备份：图片文件、同名 JSON 文件、`class_attributes.json`。对于重要项目，建议每天或每完成一个批次就复制一次整个图片目录到另一块硬盘或受控网盘。
